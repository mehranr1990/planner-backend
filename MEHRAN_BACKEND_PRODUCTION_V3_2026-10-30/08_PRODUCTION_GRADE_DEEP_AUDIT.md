## Product-grade release evidence checklist — must be demonstrably green
1. Every accepted feature mapped to exact domain command, API OpenAPI operation, authz row, persistence object, unit/integration/abuse test, owner and status; no “complete” from design alone.
2. Safety: threat model per multi-tenant surface, IDOR/nested-ID/file/feeds/search/count/export checks; revocation races and browser origin/session protections.
3. Durability: retries idempotent and atomic, worker crash recovery, schema migration/rollback on populated database, restoring from backups without resurrecting erased identities or revoked privileges.
4. Operational: RPO/RTO, load and soak testing, alerts, metrics/traces, DB performance/indexing, log redaction, secret rotation, incident/runbook and secure deployment.
5. UX/consumer contract: independently runnable validated OpenAPI JSON with operation count, schema compatibility gate and frontend integration smoke; bilingual/RTL/Jalali contracts maintained.
6. Commercial: no paid restrictions until separate activation; quota correctness and safe expiry/downgrade, purchase/payment/webhook security and taxes before any real transaction.
7. Legal/privacy: region-specific review for staff records, financial retention, social content, consent and data subject requests; user cannot authorize breaking mandatory law.
8. Release sign-off: owner accepts ADR + batch spec + acceptance evidence, real Git SHA, deployment gates and rollback procedure; no forced push or scope creep.
