# P1-03 requirements traceability

Authority: MP-IMP-001 P1-03 and shared ownership/security/time rules,
[approved ADR 0009](./adr/0009-personal-planning-semantics.md), and
[ADR 0008](./adr/0008-task-recurrence-semantics.md).

| Requirement                                                          | API / persistence                                                            | Executable verification                                                                                                                                                                                              |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Daily planning/My Day references existing Tasks                      | POST/GET planning/days/{date}; DailyPlan, scoped DailyPlanItem FK            | Unique days, duplicate creation race, single Task/multiple dates; no Task/date/history/outbox mutation; compiled smoke                                                                                               |
| Selection/order/removal                                              | PUT/DELETE days/{date}/items/{taskId}; PATCH days/{date}                     | Insert position, complete reorder, ID stability, compact removal, no-op refresh, strong/stale revisions; 100-reference cap/order uniqueness                                                                          |
| Explicit move across dates                                           | POST days/{date}/items/{taskId}/move                                         | Both plan/Task revisions, absent target revision 0, duplicate target denial, retained Task identity/dates                                                                                                            |
| Weekly planning without duplicate store                              | POST/GET weeks/{date}; WeeklyPlan composes seven days                        | Seven summaries, inherited Day references/revisions; duplicate/wrong weekday rejection; cross-user weekly denial                                                                                                     |
| Timezone/date/week preferences                                       | Recorded plan/review timezone and week firstDayOfWeek                        | Midnight/DST pure tests, leap/year boundary; original context after account travel/preference change; existing week review context                                                                                   |
| Suggestion-first rollover                                            | POST rollover/preview, no new entities/state writes                          | Missing destination stays absent; unchanged source/Task; all dispositions; repeated preview is read-only                                                                                                             |
| Explicit idempotent rollover                                         | POST rollover/commit; existing scoped receipt JSON                           | COPY/MOVE, concurrent exact replay, full-request binding, foreign receipt denial, source/target/settings race rejection, per-item stale/completed handling, injected post-write rollback                             |
| Terminal and recurring Task safety                                   | Task owner's public read contract                                            | Completed/deleted/skipped/canceled occurrence handling; no recurrence generation/Task duplication; explicit stale refresh; master selection denied                                                                   |
| Masters converted after selection stay outside My Day/metrics        | blockedItems/blockedCount/blockedAllocations metadata                        | Conversion regression verifies no master My Day item, no weekly Task count or capacity duration, blocked rollover and authorized removal                                                                             |
| Capacity based only on explicit planned work/configured availability | GET capacity; GET/PUT capacity/availability; account-owned nullable JSON     | Unknown vs zero, exact minutes, invalid/fractional/out-of-range values; advisory excess, seven-day totals, DST duration invariance, settings/availability concurrent revision arbitration                            |
| Daily/weekly private reviews                                         | PlanningReview MORNING/EVENING/WEEKLY CRUD                                   | Per-date/kind uniqueness, revisions, immutable context, cursor/date/kind bounds, cross-user reads/writes/deletion denial, metadata-only audit/no outbox, reflection log omission                                     |
| Authorization/containment                                            | Session guard, Personal Space scope, typed public facades and composite FKs  | Cross-user Task/nested/date/review/receipt checks; raw DB wrong-space/date/creator/duplicate/reference constraint tests                                                                                              |
| Existing contracts/data/architecture preserved                       | Sixth additive migration; unchanged legacy schemas; P1-02 signature baseline | Prior-schema upgrade preserves Task/checklist/attachment/recurrence/occurrence/template/filter/receipt/settings/file/audit/outbox fixtures; empty replay/repeat deploy; all prior regressions and import/cycle gates |
