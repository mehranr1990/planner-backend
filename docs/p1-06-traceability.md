Approved baseline: `34881d3084f0380485683ec93695d53aeaf92a50`.

Current progress recomputes synchronously on read; snapshots are explicit writes.
P1-06 does not dispatch source events or build a worker. No existing Task, Habit,
planning, calendar or financial state is mutated by Goals.
