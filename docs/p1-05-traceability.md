# P1-05 requirements traceability

Sources: AGENTS.md, MP-ENG-001, MP-IMP-001 §§3, 4/P1-05, 5–8; approved ADRs 0008,
0009, 0010 and [0011](adr/0011-habit-history-and-streak-semantics.md).

| Requirement                                                               | Contract/entity                                                                       | Verification                                                                                                                                                         |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Checkbox, quantity and duration measures, canonical unit/target           | `/habits`; Habit and typed schedule target; exact decimal strings/BigInt thousandths  | domain exact sum/threshold tests; contract invalid units/targets; integration canonical types/thresholds                                                             |
| Daily/weekly/selected-day/interval rules                                  | HabitSchedule version-1 definition                                                    | domain rule matrix, leap day/DST; integration anchored weekly, weekdays/interval and rest-date skip rejection                                                        |
| Create/edit/pause/resume/archive                                          | `/habits/{id}`; immutable schedule snapshots and optimistic revisions                 | integration metadata, lifecycle, archived corrections, concurrent/stale updates                                                                                      |
| Historical schedule changes require confirmation, preserve entries        | effectiveFrom/confirmHistoricalChange, schedule history route                         | domain target/version recomputation; integration confirmation, immutable prior rows/context and stale habit snapshots                                                |
| Due-day checkbox uniqueness, multiple quantity logs, nonnegative duration | HabitEntry measure/check/partial unique indexes                                       | contracts; integration concurrent checkbox/quantity, invalid values and direct SQL constraints                                                                       |
| Explicit skips, pause/rest neutrality, missed/pending behavior            | entry LOG/SKIP; stats daily outcomes                                                  | domain skip/pause/rest/miss/as-of tests; integration skip clear/partial preservation and lifecycle recomputation                                                     |
| Typed immutable correction evidence and stable logical UUID               | entry PATCH/history; same-habit root/previous/schedule FKs                            | integration checkbox toggle, immutable old values/timestamps, race and history pagination                                                                            |
| Deterministic streak/completion statistics after historical edits         | `/habits/{id}/stats`; exact threshold, explicit RANGE scope and numerator/denominator | domain and integration range outcomes, target corrections, pauses/skips and revised entries                                                                          |
| Ordered routines and scoped associations                                  | `/routines`, `/{id}`; Routine/RoutineHabit                                            | integration atomic reorder/remove/archive, paused/archived links, unique positions and concurrent/stale edits                                                        |
| Quantity-based water in canonical ML with multiple logs                   | `/habits/water-summary`; WATER QUANTITY Habit                                         | integration exact totals, rest/archive/correction, generic exclusion and cross-user summary denial                                                                   |
| Immutable local dates/timestamps/timezone context                         | schedule timezone and entry recordedAt/timezone/recordedTimezone                      | domain DST/fold/midnight/travel; integration explicit/default dates and preference change; compiled restart                                                          |
| Personal ownership on every resource/nested list/filter/stat              | verified guard, authorized scope and composite FKs                                    | integration foreign IDs/nested swaps/joins, cursors, stats/water/routines, input overposting and direct SQL denial                                                   |
| Idempotency, concurrency, audit/outbox privacy                            | 24-hour scoped receipts, locks, revisions, safe metadata events                       | integration create/log replay, checkbox/correction/routine races and private payload checks; enhanced Pino privacy regression; compiled receipt replay after restart |
| Strict Zod/OpenAPI and earlier API compatibility                          | habits schemas/paths, generated snapshot, P1-04 signatures                            | contracts and OpenAPI compatibility gate; full prior-batch regressions                                                                                               |
| Additive migrations and preservation                                      | two P1-05 migrations, five approved tables                                            | empty replay, P1-04 upgrade with full old-row snapshots including calendar, repeated deploy; ten checksums in dev/test                                               |
| Compiled API persistence and workflow smoke                               | `pnpm smoke:p1-05`                                                                    | exact water totals, typed corrections/streaks, skip/pause/resume, routine order/archive, owner denial, saved zones and receipts across actual restart                |

No P1-06 entities, habit reminders/jobs, goals, insights module, automatic routine
execution or new dependencies are introduced. Temporal choices follow approved
ADR 0011; no unapproved requirement deviation remains.
